# Gestión Académica - TorresAna

Backend del sistema de gestión y seguimiento académico.

## Tecnologías

- Java 21
- Spring Boot
- Maven
- SQL Server
- Docker
- GitHub Actions
- Docker Hub

## Estructura del proyecto

- `src/main/java`: código fuente Java.
- `src/main/resources`: configuración y recursos.
- `src/test/java`: pruebas automatizadas.
- `sql-TorresAna`: scripts de base de datos.
- `dockerfile-TorresAna`: construcción de la imagen del backend.
- `docker-compose-TorresAna`: configuración de los servicios.
- `.github/workflows`: automatización de integración y publicación.

## Configuración

La configuración de la base de datos se definirá mediante variables de entorno.
No guardar contraseñas reales en el repositorio.

## Ejecución

Las instrucciones de compilación y ejecución se agregarán cuando
se complete la configuración de Maven, Spring Boot y SQL Server.
